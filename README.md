# Wallet API

**REST API** для управления кошельками пользователей. Включает JWT-аутентификацию, защиту от брутфорса и поддержку атомарных транзакций в условиях высокой конкурентности.

## Стек технологий:
- **Язык:** Python 3.14
- **Фреймворк:** FastAPI
- **База данных:** PostgreSQL 16
- **ORM:** SQLAlchemy 2.0 (async) + asyncpg
- **Миграции:** Alembic
- **Безопасность:** JWT (PyJWT), хэширование Argon2 (pwdlib)
- **Инфраструктура:** Docker, Docker Compose
- **Тестирование:** Pytest, pytest-asyncio, httpx

## Запуск
1. Клонируйте репозиторий:
```bash
git clone https://github.com/NaceXD/wallet-api
cd wallet-api
```
2. Создайте файл .env из шаблона:
```bash
cp .env.example .env
```
3. Запустите проект:
```bash
docker compose up --build
```
4. Приложения и документация Swagger будут доступны по адресу:
    [docs](http://localhost:8000/docs)

## Эндпоинты
| Метод | Эндпоинт | Описание | Требует токен |
|-------|----------|----------|:-------------:|
| POST | /api/v1/auth/register | Регистрация | Нет |
| POST | /api/v1/auth/login | Получение JWT токена | Нет |
| POST | /api/v1/wallets | Создание кошелька | Да |
| GET | /api/v1/wallets/{wallet_id} | Получение баланса | Да |
| POST | /api/v1/wallets/{wallet_id}/operation | DEPOSIT / WITHDRAW | Да |

## Безопасность и архитектурные решения
* **JWT**: Токены подписываются алгоритмом HS256, срок жизни настраивается через ```.env```.

* **Пароли**: Хранятся в виде хэша (Argon2).

* **Rate Limiting**: Эндпоинт ```/login``` защищен от брутфорса (5 попыток в минуту). Лимитер работает в памяти.

* **Защита от перебора**: При запросе чужого кошелька возвращается ```404 Not Found``` (а не ```403```), чтобы злоумышленник не мог узнать о существовании UUID.

* **Валидация**: Сумма операции строго ```Decimal``` (```max_digits=18, decimal_places=2```), отрицательные значения и нули отсекаются.

## Конкурентность
Операции изменения баланса (особенно ```WITHDRAW```) реализованы через атомарный **SQL**-запрос:
    
```sql
UPDATE wallets SET balance = balance - :amount 
WHERE id = :id AND balance >= :amount RETURNING balance;
```

Это гарантирует, что при одновременных запросах база данных сама заблокирует строку. Если два запроса попытаются списать деньги одновременно, второй увидит уже обновленный баланс и вернет ошибку, если средств не хватит. Это предотвращает *Race Condition* (состояние гонки)
## Тесты
Проект покрыт тестами (включая проверку конкурентности).
Запуск тестов внутри Docker:

```bash
docker compose exec app pytest
```

(Тесты используют отдельную базу данных ```wallet_test_db```, которая создается и удаляется автоматически).
